# KSP AI-Driven Crime Analytics & Visualization Platform

A premium, enterprise-grade prototype designed for the Karnataka State Police (KSP). This platform provides command-center intelligence, geospatial GIS hot-spots mapping, criminal link analysis, predictive policing models, repeat offender tracking, and an interactive AI assistant.

Designed to mirror advanced software systems like Palantir and IBM Cognos, it uses a dark glassmorphic cybersecurity theme.

## 📁 Project Structure

- `index.html` - Master UI container, sidebar navigations, and CDN bindings.
- `styles.css` - Custom design tokens, glassmorphic styles, responsive grids, and animations.
- `app.js` - Logic center, mock database generator (120+ cases), Chart.js configurations, Leaflet GIS coordinates, and canvas network graph physics.

## 🚀 How to Run Locally

Since this is a fully portable client-side Single Page Application (SPA), you can run it directly:

1. Open a terminal in the project directory.
2. Start a local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8080
   ```
3. Open your browser and navigate to:
   ```text
   http://localhost:8080/
   ```

## 🧠 Key Features Included

- **District Hotspot GIS Map:** Leaflet dark matter map with pulsing high-risk alerts.
- **Spring-Physics Link Graph:** Canvas relationship diagram linking suspects, vehicles, weapons, and bank accounts with hidden association scanner.
- **AI Chatbot & Global Search:** Interactive chatbot for quick database queries and full-text search across FIR, District, and Offender entries.
- **Biometric dossiers:** Interactive dossiers tracking timelines, criminal aliases, and MO summaries.
- **Deployment Forecasts:** Monthly predictions displaying emerging threat ratios and allocation shifts.
