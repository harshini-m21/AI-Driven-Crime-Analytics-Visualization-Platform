# KSP AI-Driven Crime Analytics & Visualization Platform

A premium, enterprise-grade prototype designed for the Karnataka State Police (KSP). This platform provides command-center intelligence, geospatial GIS hot-spots mapping, criminal link analysis, predictive policing models, repeat offender tracking, and an interactive AI assistant.

Designed to mirror advanced software systems like Palantir and IBM Cognos, it uses a dark glassmorphic cybersecurity theme.

## 📁 Project Structure

- `index.html` - Master UI container, sidebar navigations, and CDN bindings.
- `styles.css` - Custom design tokens, glassmorphic styles, responsive grids, and animations.
- `app.js` - Logic center, mock database generator (120+ cases), Chart.js configurations, Leaflet GIS coordinates, and canvas network graph physics.
